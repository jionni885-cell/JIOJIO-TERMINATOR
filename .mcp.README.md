# Serveur MCP JIO

Expose la verification JIO a tout client MCP (Claude Code, opencode,
Cursor, Copilot, Hermes) :

- `jio_prove` — prouve une source contre des regles executables
- `jio_audit` — audite un fichier et derive ses regles
- `jio_contract` — renvoie le contrat de livraison (3 etats)
- `jio_skills` — liste les competences et leur declencheur
- `jio_clarify` — les 0 a 3 questions ESSENTIELLES avant de travailler ; si la
  reponse manque, l'agent doit DEMANDER a l'humain avant de commencer
- `jio_status` — l'etat d'integration du projet, lu sur le disque : artefacts,
  registre, cablage MCP, et la commande qui repare ce qui manque
- `jio_coherence` — a appeler AVANT de declarer un travail fini : sept controles
  sur le depot entier, un verdict, et la preuve de chaque constat

Transport : stdio, JSON-RPC 2.0, **zero dependance**.
