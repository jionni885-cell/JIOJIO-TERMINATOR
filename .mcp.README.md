# Serveur MCP JIO

Expose la verification JIO a tout client MCP (Claude Code, opencode,
Cursor, Copilot, Hermes) :

- `jio_prove` — prouve une source contre des regles executables
- `jio_audit` — audite un fichier et derive ses regles
- `jio_contract` — renvoie le contrat de livraison (3 etats)
- `jio_skills` — liste les competences et leur declencheur

Transport : stdio, JSON-RPC 2.0, **zero dependance**.
